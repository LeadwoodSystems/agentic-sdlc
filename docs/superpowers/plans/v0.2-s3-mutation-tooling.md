**Date:** 2026-08-05  ·  **Branch:** `sprint/v0.2-s3`

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:subagent-driven-development`

## Context (why)

`gaw` v0.13-s8 hand-rolled 4 throwaway mutation scripts (184 lines) and hit three bug
classes: a `Get-Content -Raw`/`Set-Content` round-trip that destroyed every em-dash in a
source file; LF-joined anchors that silently missed 3 of 8 mutations against CRLF sources;
and an inert mutation whose GREEN was read as evidence. The second is the serious one — **a
silently-skipped mutation reports nothing and reads as a clean run**, which is the exact
failure class the practice exists to prevent, reproduced one level up in the tooling. This
sprint ships `scripts/asdlc/mutate.js` so executing a mutation manifest is cheap and correct,
plus the reference that tells anyone why they'd want to.

## Scope

- **In:** `lib/apply-mutation.js`, `lib/manifest.js`, `lib/report.js`, `runCapture()` in
  `lib/exec.js`, `mutate.js` (loop + guards + CLI + crash safety),
  `skills/agentic-sdlc/references/test-mutation-evidence.md`, the `/checkpoint` hook.
- **Out:** mutation *generation*, parallelism across mutations, coverage integration, and
  **any `.ps1` port** (spec Decision 4 — `gaw` invokes the JS). Riders 2.2 (plan-template
  test-tier note), 2.4 (regression-sweep sequencing) and 2.5 (`gh-hygiene` failing-workflow
  check) defer to **v0.2-s4**. `size-sprint` (2.3) and the verification-log shape (2.6) are
  untouched.

## Global constraints

- **Node core only.** No `package.json`, no dependencies, no install step (`#zero-dependencies`).
- **Every function that shells out takes `{ runner }`** (`#runner-injection`). Tests stub it.
- **Never round-trip a source file through a shell.** `fs.readFileSync(p, 'utf8')` /
  `fs.writeFileSync` only.
- **Test style:** flat `test('...', () => {})` from `node:test`, `node:assert/strict`;
  `lib/` modules tested under `test/lib/`, top-level scripts under `test/`.
- **Files on disk are CRLF** (`core.autocrlf` is on). Anything rewriting a file must preserve
  what it found.

## Approach

Five modules; three are pure functions over strings, which is what makes the encoding rules
testable without a repo.

| Module | Contract |
|---|---|
| `lib/apply-mutation.js` | `applyMutation(source, find, replace) → {verdict, result}` |
| `lib/manifest.js` | `parseManifest(text) → manifest`, throws with all problems at once |
| `lib/report.js` | `renderText / renderMarkdown / renderJson / summarize (results)` |
| `lib/exec.js` | **adds** `runCapture(cmd, args, opts) → {status, stdout, stderr}` |
| `mutate.js` | dirty guard → per-mutation apply/run/classify/revert/verify → report |

`apply-mutation.js` imports `detectEol` from `lib/marker-block.js` rather than growing a
fourth copy. Importing an exported helper is not the consumer migration that file's header
warns against.

**The load-bearing detail** (spec, Encoding §2): convert `find`/`replace` **into** the file's
dominant ending and `indexOf` against the **original** source. Do not normalize the source —
round-tripping a mixed-ending file promotes every lone `\n` to `\r\n` and guarantees a
`DIRTY-REVERT`.

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const { applyMutation } = require('../../lib/apply-mutation');

// The fixture that would have caught two of the three original bug classes:
// CRLF line endings AND an em-dash. The em-dash is the exact character the
// PowerShell round-trip destroyed in gaw v0.13-s8.
const SRC_CRLF = [
  'def emit(spec):',
  '    # 1. Build the payload — shape only.',
  '    payload = build(spec)',
  '    # 2. The customer-facing send.',
  '    return send(payload)',
  '',
].join('\r\n');

test('an anchor authored with LF matches a CRLF source', () => {
  const { verdict, result } = applyMutation(
    SRC_CRLF,
    '    # 2. The customer-facing send.\n    return send(payload)',
    '    return send(payload)\n    # 2. The customer-facing send.',
  );
  assert.equal(verdict, 'APPLIED');
  assert.ok(result.includes('    return send(payload)\r\n    # 2.'));
});

test("the replacement is re-emitted in the source's own line ending", () => {
  const { result } = applyMutation(SRC_CRLF, '    payload = build(spec)', '    payload = None\n    x = 1');
  assert.ok(result.includes('    payload = None\r\n    x = 1'));
  assert.ok(!/[^\r]\n/.test(result), 'no bare LF may survive in a CRLF file');
});

test('non-ASCII outside the match survives byte-for-byte', () => {
  const { result } = applyMutation(SRC_CRLF, '    return send(payload)', '    return None');
  assert.ok(result.includes('# 1. Build the payload — shape only.'));
});

test('a mixed-ending source keeps its lone LF untouched', () => {
  // Regression guard for the approach REJECTED in the spec: normalizing the
  // whole source and re-emitting would promote this lone \n to \r\n, changing
  // bytes outside the mutation and guaranteeing a DIRTY-REVERT.
  const mixed = 'a\r\nb\nc\r\nTARGET\r\n';
  const { result } = applyMutation(mixed, 'TARGET', 'REPLACED');
  assert.equal(result, 'a\r\nb\nc\r\nREPLACED\r\n');
});

test('an absent anchor is ANCHOR-MISS with no result', () => {
  const { verdict, result } = applyMutation(SRC_CRLF, 'nowhere in the file', 'x');
  assert.equal(verdict, 'ANCHOR-MISS');
  assert.equal(result, null);
});

test('an anchor occurring twice is AMBIGUOUS-ANCHOR, never the first match', () => {
  const { verdict, result } = applyMutation('x = 1\r\ny = 2\r\nx = 1\r\n', 'x = 1', 'x = 2');
  assert.equal(verdict, 'AMBIGUOUS-ANCHOR');
  assert.equal(result, null);
});

test('overlapping occurrences also count as ambiguous', () => {
  assert.equal(applyMutation('aaa', 'aa', 'bb').verdict, 'AMBIGUOUS-ANCHOR');
});

test('a replace identical to find is NO-OP', () => {
  const { verdict, result } = applyMutation(SRC_CRLF, '    payload = build(spec)', '    payload = build(spec)');
  assert.equal(verdict, 'NO-OP');
  assert.equal(result, null);
});

test('an LF source stays LF', () => {
  const { result } = applyMutation('a\nTARGET\nb\n', 'TARGET', 'ONE\nTWO');
  assert.equal(result, 'a\nONE\nTWO\nb\n');
});
```

```js
// Applies one literal find/replace, reporting WHY it could not rather than
// guessing. Pure: no I/O, so the encoding rules below are testable without a repo.
//
// Line endings: `find`/`replace` are authored with '\n' (a model writes them into
// JSON), but source files here are CRLF. The anchor is converted INTO the file's
// ending and matched against the ORIGINAL source — the source is never normalized.
// Normalizing it and re-emitting, as the source proposal phrased it, would promote
// every lone '\n' in a mixed-ending file to '\r\n', changing bytes far outside the
// mutation and guaranteeing a DIRTY-REVERT the author would blame on themselves.
const { detectEol } = require('./marker-block');

function applyMutation(source, find, replace) {
  const eol = detectEol(source);
  const toEol = (s) => String(s).replace(/\r\n/g, '\n').replace(/\n/g, eol);
  const anchor = toEol(find);
  const body = toEol(replace);

  const at = source.indexOf(anchor);
  if (at === -1) return { verdict: 'ANCHOR-MISS', result: null };

  // Searching from at+1, not at+anchor.length, so OVERLAPPING occurrences count
  // too ('aa' in 'aaa'). Over-reporting ambiguity is the safe direction: the cost
  // is a rewritten anchor, whereas mutating one of several identical sites
  // produces a verdict that reads as evidence and is not.
  if (source.indexOf(anchor, at + 1) !== -1) {
    return { verdict: 'AMBIGUOUS-ANCHOR', result: null };
  }

  const result = source.slice(0, at) + body + source.slice(at + anchor.length);
  if (result === source) return { verdict: 'NO-OP', result: null };
  return { verdict: 'APPLIED', result };
}

module.exports = { applyMutation };
```

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const { parseManifest } = require('../../lib/manifest');

// assert.throws() returns undefined, so it cannot be used to inspect a message.
// (Corrected during execution — the first draft of this plan used
// `const err = assert.throws(...)`, which would have thrown a TypeError on
// err.message rather than asserting anything.)
function captureError(fn) {
  try {
    fn();
  } catch (err) {
    return err;
  }
  throw new assert.AssertionError({ message: 'expected the call to throw, but it did not' });
}

const VALID = JSON.stringify({
  testCommand: ['node', '--test'],
  mutations: [{
    id: 'A',
    why: 'recap must run after the send is parked',
    file: 'src/emit.js',
    find: 'send(payload)',
    replace: 'noop(payload)',
    testArgs: ['test/emit.test.js'],
    label: 'full_sequence',
    expectRed: 'recap must run after',
  }],
});

test('a valid manifest round-trips its fields', () => {
  const m = parseManifest(VALID);
  assert.deepEqual(m.testCommand, ['node', '--test']);
  assert.equal(m.mutations[0].id, 'A');
  assert.deepEqual(m.mutations[0].testArgs, ['test/emit.test.js']);
});

test('malformed JSON names itself as such', () => {
  assert.throws(() => parseManifest('{not json'), /manifest is not valid JSON/i);
});

test('a string testCommand is rejected, naming the array form', () => {
  // Guards the shape declined in spec Decision 2: a string needs shell:true,
  // which means cmd.exe on Windows and /bin/sh elsewhere — one manifest, two
  // behaviours, and a mis-split command surfaces as a RED-WRONG-REASON finding
  // rather than as tooling failure.
  const text = JSON.stringify({ testCommand: 'node --test', mutations: [] });
  assert.throws(() => parseManifest(text), /testCommand must be an array of strings/);
});

test('every required per-mutation field is named when missing', () => {
  const text = JSON.stringify({ testCommand: ['node'], mutations: [{ id: 'A' }] });
  const err = captureError(() => parseManifest(text));
  for (const field of ['file', 'find', 'replace', 'expectRed']) {
    assert.match(err.message, new RegExp(`mutation A.*${field}`));
  }
});

test('all problems are reported in one throw, not one per run', () => {
  const text = JSON.stringify({ mutations: [{ id: 'A' }, { id: 'B' }] });
  const err = captureError(() => parseManifest(text));
  assert.ok(err.message.split('\n').length >= 5, err.message);
});

test('a missing expectRed is rejected even when everything else is present', () => {
  // expectRed is what turns "it went red" into "it went red for the reason
  // predicted" — the single most valuable thing the script adds. Optional here
  // would make it optional in practice.
  const text = JSON.stringify({
    testCommand: ['node'],
    mutations: [{ id: 'A', file: 'f', find: 'a', replace: 'b' }],
  });
  assert.throws(() => parseManifest(text), /mutation A.*expectRed/);
});

test('an empty find is rejected', () => {
  // '' matches at index 0 of every file; applyMutation would call it ambiguous,
  // but the honest error is that the anchor was never authored.
  const text = JSON.stringify({
    testCommand: ['node'],
    mutations: [{ id: 'A', file: 'f', find: '', replace: 'b', expectRed: 'x' }],
  });
  assert.throws(() => parseManifest(text), /mutation A.*find.*non-empty/);
});

test('an empty replace is allowed — deleting a line is a real mutation', () => {
  const text = JSON.stringify({
    testCommand: ['node'],
    mutations: [{ id: 'A', file: 'f', find: 'a', replace: '', expectRed: 'x' }],
  });
  assert.equal(parseManifest(text).mutations[0].replace, '');
});

test('duplicate ids are rejected', () => {
  const one = { id: 'A', file: 'f', find: 'a', replace: 'b', expectRed: 'x' };
  const text = JSON.stringify({ testCommand: ['node'], mutations: [one, { ...one }] });
  assert.throws(() => parseManifest(text), /duplicate mutation id "A"/);
});

test('an empty mutations array is rejected', () => {
  assert.throws(
    () => parseManifest(JSON.stringify({ testCommand: ['node'], mutations: [] })),
    /at least one mutation/,
  );
});
```

### Task 4: `lib/report.js`

### Task 5: `mutate.js` — the loop, the guards, the CLI

**Files:** Create `scripts/asdlc/mutate.js` · Test `scripts/asdlc/test/mutate.test.js`

**Interfaces — Produces:** `assertCleanTree(cwd, {runner})`, `runMutations(cwd, manifest,

**Consumes:** `applyMutation` (Task 1), `parseManifest` (Task 2), `runCapture` (Task 3),
`renderText`/`renderMarkdown`/`renderJson`/`summarize` (Task 4), and `run` from `lib/exec.js`.

CLI: `node scripts/asdlc/mutate.js <manifest.json> [--only A,B] [--dry-run] [--json] [--allow-dirty]`

- [ ] **Step 1: Write the failing tests**, against `makeFixtureRepo` with a real trivial
      `node:test` file, so the loop is exercised end to end rather than mocked into agreement.

```js
const test = require('node:test');
const assert = require('node:assert/strict');
const fs = require('node:fs');
const path = require('node:path');
const { makeFixtureRepo } = require('./helpers/fixture-repo');
const { run } = require('../lib/exec');
const { runMutations, assertCleanTree } = require('../mutate');

// A fixture whose source is CRLF and contains an em-dash, mirroring the file
// that was corrupted in gaw v0.13-s8.
const SRC = [
  'function greet(name) {',
  '  // Politeness — required.',
  '  return "hi " + name;',
  '}',
  'module.exports = { greet };',
  '',
].join('\r\n');

const SPEC = [
  'const test = require("node:test");',
  'const assert = require("node:assert/strict");',
  'const { greet } = require("./src.js");',
  'test("greets by name", () => {',
  '  assert.equal(greet("ada"), "hi ada");',
  '});',
  '',
].join('\n');

async function fixtureWithSource() {
  const repo = await makeFixtureRepo();
  fs.writeFileSync(path.join(repo.dir, 'src.js'), SRC);
  fs.writeFileSync(path.join(repo.dir, 'src.test.js'), SPEC);
  run('git', ['add', '.'], { cwd: repo.dir });
  run('git', ['commit', '-m', 'add source'], { cwd: repo.dir });
  return repo;
}

const manifest = (mutations) => ({ testCommand: [process.execPath, '--test'], mutations });

const BREAKS_IT = {
  id: 'A', file: 'src.js',
  find: '  return "hi " + name;', replace: '  return "bye " + name;',
  testArgs: ['src.test.js'], expectRed: 'hi ada',
};

test('a mutation that breaks the asserted behaviour is RED-AS-PREDICTED', async (t) => {
  const repo = await fixtureWithSource();
  t.after(repo.cleanup);
  const results = runMutations(repo.dir, manifest([BREAKS_IT]));
  assert.equal(results[0].verdict, 'RED-AS-PREDICTED');
});

test('a RED whose output lacks expectRed is RED-WRONG-REASON', async (t) => {
  const repo = await fixtureWithSource();
```

- [ ] **Step 3: Implement `mutate.js`.** Skeleton for the part that is easy to get wrong:

```js
// Module-level so the signal handlers can reach it. At most one mutation is
// applied at a time — serializing is the point, since they all edit one working
// tree — so a single slot is sufficient, and a stack would imply a concurrency
// this tool deliberately does not have.
let inFlight = null;   // { absPath, before }

function restoreInFlight() {
  if (!inFlight) return;
  fs.writeFileSync(inFlight.absPath, inFlight.before);
  inFlight = null;
}

// Test seam only — lets the crash-safety test strand a mutation without having
// to interrupt a real run.
function __setInFlight(record) { inFlight = record; }
```

  The rest:
  - `assertCleanTree(cwd, {runner = run})` — `git status --porcelain`; non-empty throws an
    Error whose message **includes the porcelain output**, so an interrupted run leaves the
    author able to tell their own edits from a stranded mutation.
  - `runMutations(cwd, manifest, {runner = runCapture, only, dryRun})` — resolve `only`
    (an id not in the manifest throws `unknown mutation id "X"`), then for each mutation:
    read the file, `applyMutation`. A non-`APPLIED` verdict is recorded with `durationMs: 0`
    and the loop continues. On `APPLIED` with `dryRun`, record `ANCHOR-OK` and continue
    **without writing**. Otherwise set `inFlight`, write the mutated source, `try` the
    runner, `finally` restore; then re-read and byte-compare — a mismatch throws
    `DIRTY-REVERT` naming the file, aborting the run.
  - Classify: `status === 0` → `GREEN`; else `(stdout + stderr).includes(expectRed)` →
    `RED-AS-PREDICTED`; else `RED-WRONG-REASON`.
  - `main()` — parse argv; `assertCleanTree` unless `--allow-dirty`; read the manifest file
    and `parseManifest`; `runMutations`; print `renderJson` or `renderText` +
    `renderMarkdown`; `process.exit(summarize(results).isEvidence ? 0 : 1)`.
  - Register `process.on('SIGINT'|'SIGTERM'|'uncaughtException')` → `restoreInFlight()` then
    exit non-zero — **inside `main()` only**, never at module load, so importing the module
    in a test does not install process-wide handlers.
  - `module.exports = { assertCleanTree, runMutations, restoreInFlight, __setInFlight };`

## Test plan (TDD — write these first)

Each is a failing test that pins down a behaviour rather than an implementation:

- **An anchor authored with `\n` matches a CRLF source** → the silent-skip bug (3 of 8
  mutations lost) cannot recur.
- **A mixed-ending source keeps its lone LF** → guards the whole-file normalization the spec
  rejected.
- **Non-ASCII outside the match survives byte-for-byte** → the em-dash corruption cannot recur.
- **An anchor occurring twice is `AMBIGUOUS-ANCHOR`, never the first match** → a
  silently-misplaced mutation cannot produce something that reads as a verdict.
- **A missing `expectRed` is rejected** → "it went red" can never be recorded as "it went red
  for the reason predicted".
- **A bad anchor skips its own run but not the rest**, and makes the run not-evidence.
- **The file is byte-identical and `git status` clean after a run.**
- **The file is restored when the runner throws mid-mutation.**
- **A clobbered revert aborts the whole run** rather than poisoning later results.
- **`run()`'s throw-on-non-zero contract is unchanged** — the full suite is the assertion.

## Risks / open questions

- **`ANCHOR-OK` is not in the spec's verdict vocabulary.** It is a dry-run-only outcome, not

  the handoff records it as deliberate.
